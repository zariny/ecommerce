# GraphQL Schema

This page provides an interactive visualization of the project's **GraphQL schema**.

The schema is explored using **[GraphQL Voyager](https://github.com/graphql-kit/graphql-voyager)**, which provides a visual representation of GraphQL types, fields, arguments, and relationships between them.

!!! info "Generated schema"
    The GraphQL schema is generated automatically from the project's GraphQL definitions. The visualization therefore reflects the schema available at the time the documentation was generated.

<a href="voyager.html" class="md-button md-button--primary">
    Open GraphQL Voyager
</a>

!!! warning "First-time loading"
    GraphQL Voyager loads several JavaScript libraries and dependencies from external CDNs.

    On the first visit, please be patient while the required resources are downloaded and the visualization is initialized. Loading time may vary depending on your network connection.

    Once the resources are cached by your browser, subsequent visits should generally load faster.
